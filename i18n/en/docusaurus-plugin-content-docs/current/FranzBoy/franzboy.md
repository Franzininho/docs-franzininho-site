The FranzBoy board joins the Franzininho family with a new approach. Designed in the shape of a retro game console, it encourages game development and creative hacking. You can have fun and learn a lot about electronics and programming.

![FranzBoy Board](img/1.jpeg)

It features lean hardware that explores (bare-metal) the ATmega328's resources alongside an OLED display and buttons, in a badge form factor you can wear at events.

## License

Like the Franzininho DIY and Franzininho Tiny, the FranzBoy board is published as an open hardware project under the CERN Open Hardware Licence.

As defined in the license "how to", the project repository includes the following files:

- LICENSE.TXT
- cern_ohl_v_1_2_howto.pdf
- CHANGES.TXT
- COPYRIGHT.TXT
- PRODUCT.TXT

The project is available at: [github.com/Franzininho/FranzBoy](https://github.com/Franzininho/FranzBoy)
