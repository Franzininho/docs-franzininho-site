To upload code to the Franzino, first connect the USB/Serial converter to the board as shown in the figure below:

![USB/Serial Converter Connection](img/ligacao_conversor.jpg)

In the Arduino IDE, select the Arduino UNO board. Also select the serial port that was created when the USB/SERIAL converter was plugged into the computer:

![Arduino IDE configuration](img/congfigura-ide.png)

Done — now just upload your code to the Franzino board.
